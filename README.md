# Modern Eyes — Client Preview (Ben Sturdy)

Brief concept preview for **Modern Eyes** (Colorado optometry), not the final production site.

## What’s included

- **Splash / home** (`index.html`) — full-viewport hero, three location cards, short about line, and a Book section that consolidates booking onto moderneyescolorado.com (absorbing the old moderneyesco.com booking path).
- **Reviews** (`reviews.html`) — sample review themes for client discussion; final site will use Ben’s preferred real quotes.
- Shared `css/styles.css` and `js/main.js`.

## Design

Clean medical/optical look: soft whites, teal accents, DM Sans + Fraunces. Pages are marked with a **PREVIEW — concept for Ben** badge.

## Preview locally

```bash
cd /path/to/moderneyes-preview   # or ModernEyes on the Mac
python3 -m http.server 8080
```

Then open http://localhost:8080/

## Domains

- Primary: moderneyescolorado.com  
- Booking formerly on moderneyesco.com — online booking intended to live on the primary domain.
